New here? Controls & connection help

Use a current version of Chrome, Firefox, Edge, or Safari. A desktop with a keyboard and mouse gives the best experience. Click the game to focus it, use the mouse to interact, and type to chat. Low detail can help on slower devices.

The client connects to the 2004Scape world service and downloads game files. You need an account for the selected server; see 2004Scape for account information and live worlds. GitHub Pages hosts the client; it does not host the game server. A world may be unavailable or require membership.

World 0 is for a local development server. Worlds 998 and 999 require a separately bundled peer or worker server and game data. They are not included in this website.
