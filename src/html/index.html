Download local server setup (.zip) Setup guide

The setup installs and starts a game server. Requires Node.js 22.22.1+, Git, Java 17+, and internet for the first setup. Extract the ZIP, run node setup.cjs, then node start.cjs. Open the local link printed in the terminal.

Locked-down Chromebook? The local server needs Linux support. Without it, use a public world above or open a launcher hosted on another computer over HTTPS. Chromebook options need no extensions; your administrator must allow the site and game connections.

Use the server's web port. The client tries WebSockets on this port, then port 43595. HTTP servers need the HTTP launcher at localhost:8080; HTTPS Pages needs an HTTPS/WSS server.

What do I need to play?

A current Chrome, Firefox, Edge, or Safari browser and an account on the selected 2004Scape server. Visit 2004Scape for account information. Some worlds require membership.

Which graphics setting should I choose?

High detail gives you the full classic presentation. Low detail reduces the load on your device. You can change this before each launch; your choice is remembered here.

My world isn't loading. What now?

Retry the connection or return to the launcher and choose another world. The world service and game files need to be available. This website hosts the browser client; game servers are separate services. A normal build needs an internet connection.

Can I use the tools without playing?

Yes. Open a tool directly from the toolkit above. Most tools download data from the game services. The cache viewer and JagEd let you bring cache files from your computer.
